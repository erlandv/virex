The MarkChat Website Live Chat widget enables real-time visitor engagement on your web store or landing pages. It features asynchronous loading, mobile-first responsive drawers, identity verification, and customizable brand accents.

---

## 1. Creating a Website Channel in MarkChat

1. Open your MarkChat dashboard and navigate to **Settings > Inboxes**.
2. Click **Add Inbox** and select **Website**.
3. Configure the initial channel properties:
   - **Website Name:** e.g., *Official Webstore Live Support*
   - **Website Domain:** Enter your root URL (e.g., `https://markchat.co.ke`).
   - **Widget Color:** Choose your primary brand hex color (e.g., `#2563EB`).
4. Click **Create Website Channel**.

MarkChat will generate a unique JavaScript snippet containing your `websiteToken` and script source.

---

## 2. Installation: Embedding the JavaScript Snippet

Copy the code snippet generated by MarkChat and paste it into your HTML template immediately before the closing `</body>` tag on all pages where you want the chat widget to appear:

```html
<script>
  (function(d,t) {
    var BASE_URL = "https://app.markchat.co.ke";
    var g = d.createElement(t), s = d.getElementsByTagName(t)[0];
    g.src = BASE_URL + "/packs/js/sdk.js";
    g.defer = true;
    g.async = true;
    s.parentNode.insertBefore(g,s);
    g.onload = function() {
      window.chatwootSDK.run({
        websiteToken: 'YOUR_WEBSITE_TOKEN_HERE',
        baseUrl: BASE_URL
      });
    };
  })(document,"script");
</script>
```

Replace `YOUR_WEBSITE_TOKEN_HERE` with your actual token from the MarkChat inbox settings.

### Installation on Frameworks & CMSs

- **Next.js / React:** Place the script inside a `useEffect` hook or use `next/script` with `strategy="lazyOnload"`.
- **Astro:** Add the snippet inside a `<script is:inline>` tag in your base layout.
- **WordPress:** Add the snippet via your child theme's `footer.php` or install a header/footer injection plugin.
- **Shopify:** Open **Online Store > Themes > Edit Code**, open `theme.liquid`, and paste the script directly above `</body>`.

## 3. Customizing Widget Appearance & Behavior

In **Settings > Inboxes > [Your Website Inbox] > Configuration**, you can tune widget parameters:

- **Greeting Message:** Set an automated prompt (e.g., *"Habari! How can our Nairobi team assist you today?"*).
- **Reply Time Expectation:** Display response estimates such as *"Typically replies within 5 minutes"*.
- **Pre-Chat Form:** Require visitors to enter their **Full Name**, **Email Address**, and **Kenyan Mobile Number** before starting a chat. This automatically creates a customer record for immediate `/stk` M-Pesa prompting.
- **Allowed Domains:** Restrict widget rendering to specific production domains, preventing unauthorized third-party sites from embedding your chat widget.

## 4. Identifying Authenticated Users via SDK

If your website has logged-in users, you can pass their identity directly to the MarkChat widget to display their authenticated profile and prevent spoofing:

```javascript
window.addEventListener('chatwoot:ready', function () {
  window.$chatwoot.setUser('USER_IDENTIFIER_123', {
    name: 'Juma Mwangi',
    email: 'juma@example.com',
    phone_number: '+254712345678',
    avatar_url: 'https://example.com/avatars/juma.jpg',
    identifier_hash: 'HMAC_SHA256_HASH' // Optional cryptographic HMAC verification
  });

  // Set custom customer attributes
  window.$chatwoot.setCustomAttributes({
    loyalty_tier: 'Gold',
    city: 'Nairobi',
    last_order_id: 'ORD-98421'
  });
});
```

## 5. Controlling the Widget Programmatically

The MarkChat SDK exposes client-side methods for custom UI triggers:

```javascript
// Open the chat widget
window.$chatwoot.toggle('open');

// Close the chat widget
window.$chatwoot.toggle('close');

// Send a pre-filled message text into the input field
window.$chatwoot.setTextMessage('I would like to pay via M-Pesa for order #412');
```

## Troubleshooting

### Widget does not appear on the website
- Verify that `BASE_URL` and `websiteToken` are correct.
- Check the browser developer console (`F12`) for Content Security Policy (CSP) errors blocking `sdk.js`.
- Confirm that your site domain is listed under **Allowed Domains** in the MarkChat inbox settings.
