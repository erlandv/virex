# STAGE 2.6 — HOMEPAGE AND NAVIGATION IMPROVEMENTS

## Objective
Improve homepage clarity, product positioning, navigation structure and conversion paths without replacing the existing Virex design foundation.

## Requirements
- Preserve existing typography, global styles, spacing, colour tokens and component conventions.
- Inspect all existing pages before changing navigation.
- Make navigation reflect real, substantiated product capabilities.
- Remove or correct links to unsupported or nonexistent destinations.
- Ensure every visible navigation item leads to a meaningful working route.
- Preserve responsive desktop and mobile behaviour.
- Keep login and registration destinations consistent with the existing approved configuration.
- Improve homepage messaging without unsupported product promises.
- Use genuine product screenshots where available.
- Use accurate interface mockups only when they reflect verified functionality.
- Avoid generic filler, fabricated customer proof and decorative feature claims.

Do not redesign the entire website or replace the Virex template.

## Approval gate
Provide visual and navigation review evidence, including desktop and mobile checks. Stop for owner approval before Stage 2.7.
