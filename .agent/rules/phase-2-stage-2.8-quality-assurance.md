# STAGE 2.8 — SEO, ACCESSIBILITY AND REGRESSION TESTING

## Objective
Perform final quality assurance across the approved Phase 2 work.

## SEO checks
- Page titles and meta descriptions.
- Canonical URLs and indexing directives.
- Sitemap and robots configuration.
- Open Graph and social metadata.
- Heading structure and internal linking.
- Structured data only where accurate and appropriate.

## Accessibility checks
- Semantic HTML.
- Keyboard navigation.
- Visible focus states.
- Form labels and error messages.
- Colour contrast.
- Accessible menus and interactive controls.
- Meaningful alternative text.

## Regression checks
- Desktop, tablet and mobile layouts.
- Dark and light themes.
- Existing routes and dynamic routes.
- Navigation and authentication destinations.
- Contact and lead forms.
- CMS permissions and CRUD.
- Static content generation.
- Controlled publishing success and failure.
- Broken links and missing assets.
- Browser console and build errors.

## Verification discipline
Run appropriate existing project checks and production build commands where safe.

Report the actual commands and results. Distinguish tests not run, tests failed and tests passed. Do not fabricate test evidence.

Do not deploy or publish production.

## Final approval gate
Provide the complete Phase 2 acceptance report and outstanding-risk register. Wait for explicit final owner acceptance.
